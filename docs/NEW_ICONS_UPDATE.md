## 🔄 Como Atualizar nos Dispositivos

### 📱 Android Chrome

Para ver os novos ícones:

```bash
1️⃣ DESINSTALE o app atual:
   - Tela inicial → Segure ícone DEEDO Ponto
   - Desinstalar

2️⃣ LIMPE o cache do Chrome:
   - ⚙️ Configurações → Privacidade
   - Limpar dados de navegação
   - Marcar: Cache e cookies
   - Limpar

3️⃣ REINSTALE o app:
   - Acesse: http://[ip]/ponto/public/
   - Botão ⊕ → Instalar
   - ✅ Novo ícone aparece!

4️⃣ VERIFIQUE:
   - Tela inicial
   - Gaveta de apps
   - Tela de apps recentes
   - ✅ Logo DEEDO Ponto novo deve aparecer
```

---

### 🍎 Safari iOS

Para ver os novos ícones:

```bash
1️⃣ REMOVA o app atual:
   - Tela inicial → Segure ícone
   - Remover App → Remover da Tela de Início

2️⃣ LIMPE o cache do Safari:
   - Ajustes → Safari
   - Limpar Histórico e Dados do Site
   - Limpar

3️⃣ REINSTALE:
   - Safari → Acesse o site
   - Compartilhar 📤 → Adicionar à Tela de Início
   - ✅ Novo ícone (deedo_ponto_logo) aparece!

4️⃣ VERIFIQUE:
   - Tela inicial do iPhone/iPad
   - ✅ Logo DEEDO Ponto quadrado
```

---

### 💻 Safari macOS

```bash
1️⃣ REMOVA da Dock:
   - Dock → Arraste ícone para fora
   - Solte (desaparece)

2️⃣ LIMPE cache:
   - Safari → Limpar Histórico

3️⃣ REINSTALE:
   - Arquivo → Adicionar à Dock
   - ✅ Novo ícone na Dock
```
